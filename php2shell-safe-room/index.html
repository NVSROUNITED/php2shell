MISSION BRIEF

What you will learn

A

Before application code

Follow the request lifecycle: the PHP runtime can parse multipart input and process upload-progress state before the application starts.

B

Two related CVEs

Compare CVE-2026-109618 (OOM corruption) with CVE-2026-109619 (stale global state / use-after-free).

C

Defensive response

Separate a complete runtime update from temporary, incomplete exposure-reduction measures.

Core ideaA worker can retain request-owned state after that request's memory is released. A later early-initialization path may encounter stale state before normal request setup resets it.
02

REQUEST LIFECYCLE

Where the boundary matters

  1. 01
    HTTP request arrives

    In the scenario, the request is handled by a PHP-capable web stack.

  2. 02
    Runtime parses request data

    Multipart parsing and upload-progress handling can occur before userland application code.

  3. 03
    Exceptional exit interrupts cleanup

    An out-of-memory condition or another fatal interruption can leave internal state incompletely reset.

  4. 04
    Worker state crosses a request boundary

    If the same worker is reused, an early consumer may encounter stale state before normal initialization.

Illustrative lifecycle only. It does not describe a reproducible request or provide an exploitation recipe.

Instructor notes and debrief

Expected takeaway: these are PHP runtime flaws, so clean application code does not by itself remove the affected engine behavior. The two advisories describe different paths to use-after-free / invalid request state and RCE impact. The official PHP release notice is the primary remediation source.

Discussion prompts: Which evidence is simulated? What must be verified on the actual fleet? Which mitigations are temporary, and what operational regressions might they cause? Why does a scanner that only reads one page not establish whether the PHP runtime is patched?

Scope: this room is an awareness and defensive-triage exercise. It is not a vulnerability reproduction, penetration test, or certification.
